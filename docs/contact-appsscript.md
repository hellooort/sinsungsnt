# 홈페이지 문의를 구글 스프레드시트와 메일로 받기 (앱스스크립트)

신성에스엔티 홈페이지 문의 폼을 **구글 스프레드시트에 기록하고, 동시에 `shinsung0822@daum.net`으로 알림 메일을 보내는** 방법입니다.
별도 서비스에 가입하지 않고 구글 계정 하나로 처리합니다. 나비창·유민스테인레스와 같은 방식입니다.

## 전체 구조

```
고객이 폼 작성 (www.sntg.co.kr)
   ↓
홈페이지 서버 (/api/contact)   ← 입력값 검증, 비밀값 첨부
   ↓
앱스스크립트 웹앱 (doPost)
   ↓                    ↓
스프레드시트 기록      알림 메일 발송 (Gmail)
```

브라우저에서 앱스스크립트로 바로 보내지 않고 홈페이지 서버를 한 번 거칩니다. 그래야 웹앱 주소가 화면에 드러나지 않고, 자동 프로그램이 함부로 넣는 글을 걸러낼 수 있습니다.

## 1. 스프레드시트와 스크립트 만들기

1. 메일을 보낼 구글 계정으로 로그인한 뒤 새 스프레드시트를 만듭니다. 이름은 `신성에스엔티 홈페이지 문의`로 정합니다.
2. 메뉴에서 **확장 프로그램 > Apps Script** 를 엽니다.
3. 기본으로 들어 있는 `function myFunction() {}` 을 모두 지우고, 같은 폴더의 `contact-appsscript.gs` 내용을 전부 붙여 넣습니다.
4. 맨 위 세 줄을 확인합니다.
   - `TO` : 문의 알림을 받을 주소. 지금은 `shinsung0822@daum.net` 입니다. 여러 명이면 쉼표로 구분합니다.
   - `SECRET` : Vercel 환경변수 `CONTACT_SECRET` 과 같은 값이어야 합니다.
   - `SHEET_NAME` : 기록할 시트 이름. 그대로 두어도 됩니다.
5. 저장합니다.

## 2. 권한 승인하고 시험해 보기

1. 상단 함수 목록에서 `testSend` 를 고르고 **실행**을 누릅니다.
2. 권한 승인 창이 뜹니다. 계정을 고르고, "이 앱은 확인되지 않았습니다" 화면이 나오면 **고급 > (프로젝트 이름)(으)로 이동** 을 눌러 허용합니다. 본인이 만든 스크립트라 안전합니다.
3. 실행이 끝나면 스프레드시트에 테스트 한 줄이 쌓이고, `TO` 주소로 메일이 도착합니다. 두 가지가 모두 확인되어야 다음으로 넘어갑니다.

## 3. 웹앱으로 배포하기

1. 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
2. 톱니바퀴에서 **웹 앱** 을 고릅니다.
3. 설정을 이렇게 맞춥니다.
   - 설명: `문의 접수`
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. 배포를 누르면 `https://script.google.com/macros/s/.../exec` 형태의 **웹앱 URL** 이 나옵니다. 이 주소를 복사해 둡니다.

> 코드를 고친 뒤에는 **배포 > 배포 관리 > 편집(연필) > 버전: 새 버전 > 배포** 를 해야 반영됩니다. 새 배포를 또 만들면 주소가 바뀌니 주의합니다.

## 4. 홈페이지에 연결하기

Vercel 프로젝트는 `hellooorts-projects` 팀의 `sinsungsnt` 입니다. 환경변수 두 가지를 넣고 다시 배포합니다.

| 이름 | 값 |
|---|---|
| `CONTACT_WEBHOOK_URL` | 3번에서 복사한 웹앱 URL |
| `CONTACT_SECRET` | 스크립트의 `SECRET` 과 같은 값 |

```bash
vercel env add CONTACT_WEBHOOK_URL production --scope hellooorts-projects
vercel env add CONTACT_SECRET production --scope hellooorts-projects
vercel deploy --prod --yes --scope hellooorts-projects
```

## 5. 확인

1. www.sntg.co.kr 문의하기에서 회사명·담당자명·연락처·문의 내용을 넣고 [문의하기]를 누릅니다.
2. 화면에 **"문의가 접수되었습니다"** 가 뜨면 성공입니다. 스프레드시트에 줄이 쌓이고 메일이 도착합니다.
3. 메일 프로그램이 열리면 아직 연결되지 않은 것입니다. 환경변수 이름과 비밀값, 웹앱 접근 권한(모든 사용자)을 다시 확인합니다.

## 알아 둘 점

- 무료 구글 계정의 하루 메일 발송 한도는 100통입니다. 문의 알림 용도로는 넉넉합니다.
- 다음 메일함에서 처음 몇 통이 스팸함으로 갈 수 있습니다. 그렇다면 스팸 아님으로 표시하고 보낸 주소를 주소록에 넣어 둡니다.
- 문의 내용이 스프레드시트에 남으므로 메일을 놓쳐도 기록은 사라지지 않습니다.
- 문의자가 이메일을 남겼으면 받은 메일에서 바로 회신할 수 있습니다(Reply-To).
- 비밀값을 바꾸면 스크립트와 환경변수 양쪽을 같이 바꿔야 합니다.
- 홈페이지 쪽 연결 코드는 `api/contact.ts` 에 있습니다. 환경변수가 없거나 접수에 실패하면 방문자의 메일 프로그램을 `shinsung0822@daum.net`으로 여는 화면으로 넘어가서, 설정 전후로 문의가 끊기지 않습니다.
